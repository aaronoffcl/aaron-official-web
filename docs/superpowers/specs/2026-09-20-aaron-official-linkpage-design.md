# Aaron Official リンクページ 設計仕様書

- 日付: 2026-09-20
- 対象: 新規サイト「Aaron Official」— TikTok/Instagramプロフィール用のミニ公式サイト
- プロジェクトルート: `/Users/aaronkuwamoto/Desktop/Aaron_Official_Web`
- 既存の `AaronIntelligence_Web`（AI事業のコーポレートサイト）とは別ブランド・別リポジトリ

## 1. 背景・目的

TikTok（`@aaron.nottiktoker`、フォロワー約4,000〜1,000人規模のアカウントを含め複数運用）のフォロワーが1,000人を超え、プロフィールにURLを貼れるようになる。現在は instabio.cc（Linktree系サービス）を使っているが、広告が入り品質が低いため、自作のリンクページに置き換えたい。

- 主目的: TikTokからの流入をYouTubeチャンネルへ誘導すること
- 副次目的: 将来的に「アーティストの公式ページ」らしい見た目・拡張性を持たせること
- 運用方針: この発信活動を長期的に継続する前提で、ずっと使い続けられるサイトにする
- 想定トラフィック: 過去に運用していたアカウント（BAN済み）でも1ヶ月1万人以上の訪問実績があり、中堅規模のアクセスを想定する

## 2. スコープ

1ページ構成の静的サイト（ビルドツールなし、素のHTML/CSS/JS）。`AaronIntelligence_Web` と同じ技術方針を踏襲する。

- モバイル最優先のレイアウト（TikTok経由の訪問者はほぼ100%スマホ）。デスクトップでも崩れないようにするが、デザイン検証はモバイル幅を主軸に行う
- YouTubeへの導線を最も目立たせる（他のリンクより優先度を上げる）
- バックエンド処理・フォームは範囲外

## 3. 参考にした既存ページ

現行の instabio.cc ページ（`instabio.cc/aaronofficial`）の構成:
- 中央円形アバター（モノクロ写真）
- タイトル「All Aaron's social media」
- 説明文＋矢印で下のリンクへ誘導
- Instagram / YouTube のアイコンボタン（横並び）
- その下に「Profile」見出し＋写真ギャラリー

この構成の骨格（アバター→誘導文→リンクボタン→動画/写真）を踏襲しつつ、広告なし・高品質デザインに作り直す。

## 4. ページ構成（上から）

1. **ヘッダー/プロフィール**
   - モノクロの丸型プロフィール写真
   - 名前「Aaron / アーロン」
   - 1行キャッチコピー: 「毎日更新中」をデフォルト案とする（現行instabioページの文言を踏襲。変更したい場合は実装時に差し替え可）
2. **メインCTA: YouTubeボタン**
   - 他のリンクより明確に大きく・上位に配置（例: 幅いっぱいの大きめボタン、赤系アクセント）
   - タップ後は新しいタブ/アプリでYouTubeチャンネルを開く
3. **サブリンク行**
   - Instagram、X(Twitter) など。アイコン+ラベルのボタンをYouTubeボタンより小さく横並び/縦積みで配置
   - リンク一覧はJSの配列で管理し、後からTikTok本アカウント等を追加しやすくする
4. **動画セクション（最新/人気動画）**
   - YouTubeのサムネイル画像を数本（3〜6本目安）カード形式で並べる
   - 各カードはサムネイル＋タイトル＋再生ボタンのオーバーレイ。タップでYouTube側の該当動画へ遷移（軽量なサムネイルリンク方式を採用し、埋め込みiframeによるページの重さ・離脱防止のジレンマを避ける。目的が「YouTubeへの誘導」であるため、この方式の方が目的に合致する）
   - 動画データもJSの配列（動画ID・タイトル・サムネイルURL）で管理し、更新を容易にする
5. **フッター**
   - コピーライト表記のみ

## 5. ビジュアルデザイン方針

- 「アーティスト風」の暗め・モノクロ寄りのトーンを仮デザインとして採用（ユーザーから追って参考画像が届き次第、色味・雰囲気を調整する前提）
- 背景: ダーク基調（黒〜濃いグレー）。instabio版のような紫グラデーションではなく、写真素材のモノクロトーンに馴染む落ち着いた背景にする
- タイポグラフィ: 見出しは主張のある英字書体、本文は視認性重視のシンプルなサンセリフ
- モーション: 控えめなフェードイン程度に留め、TikTok経由の低速回線でも軽く動作することを優先する

## 6. データ構造（更新のしやすさ）

`script.js` 内に以下のような設定オブジェクトを用意し、リンク・動画の追加/変更をこの部分の編集だけで完結させる。

```js
const LINKS = [
  { label: "Instagram", url: "https://instagram.com/aaronsta6ram", icon: "instagram" },
  // X(Twitter)・TikTok本アカウント等はURL確定後に追加
];

const VIDEOS = [
  { id: "xxxxxxxxxxx", title: "動画タイトル" }, // 動画IDはユーザーから受領後に差し替え
];
```

判明済みの実リンク:
- YouTube（メインCTA）: `https://www.youtube.com/@aaron.youtube.official`
- Instagram: `https://instagram.com/aaronsta6ram`
- X(Twitter)・TikTok本アカウント・動画3〜6本のID: 実装開始前にユーザーへ確認

サムネイルURLは動画IDから `https://i.ytimg.com/vi/{id}/hqdefault.jpg` の形式で自動生成する。

## 7. 技術構成

- `index.html` / `style.css` / `script.js` の3ファイル構成（`AaronIntelligence_Web` と同一パターン）
- ビルドツールなし
- ホスティング: GitHub Pages（無料）。ユーザーがカスタムドメイン（例: aaronofficial.com 系、取得予定）を取得次第、`CNAME` ファイルとDNS設定で紐付ける（本スペックでは実装のみ行い、ドメイン紐付け作業はドメイン取得後にユーザーと一緒に行う）
- アセット: `assets/` にプロフィール写真・favicon等を配置（ユーザーから素材提供、または既存SNSの写真を使用）

## 8. テスト・検証方針

- ブラウザプレビュー（Claude Browser）でモバイル幅（375px前後）を主軸に表示確認
- YouTubeボタン・サブリンク・動画カードのタップ/クリック動作を確認
- デスクトップ幅でもレイアウト崩れがないことを確認
- `prefers-reduced-motion` 等の配慮（アニメーションは最小限のため簡易確認で可）

## 9. 除外事項（スコープ外）

- カスタムドメインの実際のDNS設定・GitHub Pagesへの紐付け作業（ドメイン取得後に別途対応）
- 自己紹介文の本格的な執筆、写真ギャラリーページ（今回のセクション選定では「動画埋め込み」のみを採用。将来追加しやすい構造にはしておく）
- 動画埋め込みのiframe方式（軽量なサムネイルリンク方式を採用したため対象外）
- CMS化・多言語対応
